# Codexへの作業依頼

ずんだもんを窓口に、本人のCodexへ依頼します。調査だけでなく編集・テストにも対応し、進捗・質問・承認要求・結果を画面へ返します。ずんだもんAI専用の実行制限はありません。実行する権限・モデル・ツールは、そのMacのCodex設定に従います。

## 使い方

- `CodexにずんだもんAIの表示を直して、テストして`
- `AI道場の進捗確認して コーデックス`
- `Codex: この内容で資料を作って`
- `Codexに続けて修正して`

Codexを宛先にした依頼を送ると開始します。「Codexについて教えて」は通常の会話です。直前の会話12発言（最大16000文字）を参考として渡すので「この内容」も参照できます。写真の実データはこの接続へ渡していません。

プロジェクト一覧は依頼ごとにCodex app-serverの `project/list` から取得します。独自の許可リスト・手入力一覧は持ちません。名前が一意に一致する場合は、そのプロジェクトの作業ディレクトリとIDで開始します。同名・複数対象・曖昧な依頼はCodexが判断・確認します。一覧は作業対象を限定するためのものではありません。

同じトーク内で前の依頼が残っている場合、追加の依頼は本人の前回のCodexスレッドを再開します。別プロジェクト名を指定した場合や「新しいタスク」などと依頼した場合は新しいスレッドで開始します。以前の調査専用スレッドは再利用しません。

## 質問・承認・停止

通常時の進捗欄は2行です。Codexから確認が届くと「Codexの確認に回答」が表示されます。開くと質問や実行予定の内容を読めます。回答・許可・拒否を、その要求に対応するCodexへ返します。時間が経っただけで承認することはありません。端末を再読み込みしてもサーバーが動いていれば確認を再表示できます。

対応する要求: コマンド実行、ファイル変更、追加アクセス許可、ユーザーへの質問、MCPのURL確認と基本フォーム（文字・数値・真偽値）。複雑なMCPフォーム、外部クライアント専用動的ツールや認証更新要求は未対応としてCodexへ返します。Codexデスクトップの画面操作ツールをそのまま提供する機能ではありません。

「作業を停止」または通常の生成停止ボタンで中断できます。既に行った変更を巻き戻す操作ではありません。同時実行は1件。以前の6分で停止する制限は撤去しています。

## 結果と再読み込み

完了結果はトークへ返り、「全文」で全体を読めます。再読み込み後に完成した結果は「結果をトークに表示」、または `Codexの結果を見せて` で受け取れます。サーバーを終了すると作業は中断され、自動再実行しません。改めて依頼すれば、同じトークから継続できます。

具体的なトークン・秘密鍵などは結果の保存前に伏せます。ファイルパスや「APIキー」という用語自体は伏せません。秘密情報の完全検出を保証する処理ではありません。

## 接続条件

「メニュー → AI接続 → Codex」で接続状態、設定モデル、登録プロジェクト数を確認できます。「Codexの接続を確認」は作業を開始せず、現在のログインと設定を読み取ります。

既存の `.env.connection.local` に設定します。

```dotenv
ZUNDAMON_CODEX_ENABLED=true
ZUNDAMON_CODEX_BINARY=codex
```

そのMacの本人のCodexログインを使います。APIキーの新規発行は不要です。Macとアプリサーバーの起動が必要です。本人限定の認証とOrigin確認を維持し、app-serverは非公開のstdio接続で動かします。任意のRPCをブラウザへ公開しません。

Codex設定の sandbox・approval・model・effort・MCP・プラグインをずんだもん側で上書きしません。Codexの登録プロジェクト取得は実験的APIのため、CLI更新時には互換性確認が必要です。現状は接続しているMacのプロジェクト・実行環境が対象で、別ホストへの自動転送は実装していません。

依頼・状態・結果・thread/turn ID・未回答の質問は `data/codex-jobs/` に本人別で最大50件保存します。質問への入力値そのものはこの保存ファイルへ残さずCodexに返します。Codex自身の履歴には残る場合があります。結果をトークへ返すと通常の会話保存にも残ります。

参考: [Codex app-server](https://learn.chatgpt.com/docs/app-server)。

## 呼びかけと進捗確認（2026-09-13）
「コーデックスくんにサンプルアプリの進捗聞いて」など、敬称と「聞いて／きいて／尋ねて」も依頼として扱う。依頼直後の「今は待ち？」「終わった？」はその依頼IDのCodex状態を取得し、Web検索や新規作業へ送らない。別の話題に移った場合は通常会話へ戻す。受け付け・取得に失敗したときは状態不明と案内し、無関係な最新作業で代用しない。過去の依頼を自動で再実行する変更ではない。
