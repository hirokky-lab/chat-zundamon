# 自分のサービスを準備する

設置者向けの手順です。過去の開発記録にある作者のURL・プロジェクトID・接続済みという記載は使わず、すべて自分の環境で準備してください。各サービスの管理画面の名称や利用条件は変わるため、表示される案内も確認してください。

## 新規プロジェクトを作れない場合

無料枠の上限に達していると、新規プロジェクトを作成できない場合がある。既存アプリを止めるための一時停止・削除や、有料プランへの変更を自動で行わない。本人に対象と影響を説明して判断を確認する。先にローカルの独立DBで検証を進めることもできるが、Googleログインやクラウド同期の実確認とは区別する。

## 保存先とログイン

1. 自分のSupabaseアカウントに、このアプリ専用のプロジェクトを用意する。YUIや他アプリのDBを転用しない。
2. リポジトリの `supabase/migrations/` を、ファイル名のバージョン順に適用する。初期設定画面はマイグレーションを実行しない。既存DBなら先に適用履歴を確認し、再適用やリセットをしない。ローカル検証SQLを実際の個人データのあるDBに実行しない。
3. Supabase AuthでGoogleログインを準備する。Google Cloud側では自分のOAuthクライアントを用意し、Supabaseがそのプロジェクトに対して表示するAuthコールバックURLを登録する。クライアントID・シークレットはSupabase側のGoogleプロバイダーへ設定する。
4. 自分のアプリを開くHTTPS入口を決め、Supabase AuthのSite URLと許可する戻り先を合わせる。別端末でも同じ入口を使う。
5. 初期設定画面へ、プロジェクトURL、公開用キー、サーバー用キー、自分のログイン用メールアドレス、アプリのHTTPS入口を入力する。

接続モードは127.0.0.1:4393にWebとAPIを提供する。HTTPS入口はこのポートへ転送する。APIの4384番や初期設定のランダムポートをそのまま公開しない。現在は永続ディスクと稼働中のNodeサーバーが必要で、PCを停止すればそのPCのサーバーも停止する。

## AIと声

- OpenAI：自分のAPIキーを初期設定へ入力する。現在のモデルはアプリ側で固定。接続確認はモデル情報の取得であり、会話生成・残高の確認ではない。
- さくら：自分のAI Engineキーを初期設定へ入力する。実際の声はログイン後の「声の設定」で試聴する。料金は自分の契約に従う。
- TTS QUEST：現行の接続方法ではキー不要。制限や待ち時間がある。初期設定で選択しても自動再生しない。

## カレンダー・Drive・Gmail

これはGoogleログインとは別の設定。

1. 自分のGoogle Cloudプロジェクトで必要なAPIとOAuth同意画面を準備する。テスト公開の場合は利用するアカウントが対象に含まれるか確認する。
2. ウェブアプリ用OAuthクライアントを用意し、初期設定が表示するリダイレクトURIを登録する。URIは自分のアプリのHTTPS入口に `/api/google-calendar-tasks/callback` を加えたもの。Supabase Authのコールバックではない。
3. 初期設定へクライアントID・シークレットを入力する。トークン暗号鍵はアプリがこの環境に新規作成する。
4. アプリ起動後、「Google連携」から必要なサービスへ接続して利用許可を行う。初期設定への登録だけで、Googleのデータに接続済みとはならない。

接続情報や権限を変更した場合は、各サービスの状態表示を確認する。書き込みの検証は、本人が承認したテスト対象で行う。

## 起動後

[AI向けセットアップガイド](setup-guide.md) の確認表で、ログイン・会話・保存・端末間同期を個別に確認する。DB基本テーブルへの接続だけで、写真保存や記憶処理など全機能が正常と判断しない。

現時点で新しいクラウド契約から全機能を通す検証は未完了。素材の再配布条件も [キャラクター素材](character-art.md) を確認する。
