# セリフ欄の積み上げ表示

2026-09-12のユーザー指示により、横スワイプとページドットを廃止。
新しいセリフを下へ追加し、それまでの欄を320msで上に移動する。PC・スマホとも直近2個分の高さに収め、同じ返答のセリフを上下スクロールで読み返せる。画面が低いときは44dvhを上限にする。前のターンのセリフは含めず、次の送信では考え中表示へ切り替える。全ターンの全文はトークに残る。

`src/speech-segments.ts` が表示と音声合成で共通の区切りを作る。段落と句点を優先し、約90文字で区切るが連続する漢字の途中では切らない。通常会話の音声再生開始コールバックで、その区切りだけをセリフ欄に追加する。音声生成完了時や推定秒数では表示を進めない。

読み上げ中は次の1区切りだけ合成を先行準備する。発声開始前には先行取得しない。新しい送信・キャンセル後の古いコールバックは表示に反映しない。音声失敗・終了時はトーク本文の表示へ戻す。音声OFFでは表示済みの本文を使う。

`StageSpeech` は現在の返答の欄をすべて保持し、DOM位置差を使って既存の欄を上へ動かす。末尾を見ている間だけ新しい欄を追従する。上へスクロールしている間は窓の高さとスクロール位置を保ち、末尾へ戻すと追従を再開する。アニメーションで一時的に伸びるscrollHeightを追従判定に使わず、本文のレイアウト上の高さを使う。動きを減らす設定ではアニメーションを止める。返答のリンクは引き続き表示する。

検証：セリフ・音声・トーク関連5ファイル30テスト、Web型検査。実コンポーネントを使う分離ブラウザで1280/892/390/320px、2個分の表示・上への読み返し・追加時の位置保持・末尾追従の再開・次のターンへの切り替え・入力欄との非重複・横はみ出しなし・動きを減らす設定を確認。再実行はViteを4386で起動して `node scripts/verify-stage-speech.mjs`。実端末での音声の聞こえ方と発声の間合いはユーザー確認待ち。
