# 公開版の検証範囲

2026-09-13時点。個人用の開発フォルダからコードを取り出し、過去のGit履歴・個人データ・外部素材を引き継がない公開用リポジトリとして作成しました。

## 確認したこと

- 設定ファイル・モデルを持たない公開用コピーで、`pnpm install --frozen-lockfile`、全パッケージの型検査、通常Webビルドが成功。
- ドメインのテスト256件、サーバー1170件が成功。サーバーの環境依存6件はスキップ。
- Webは通常の109ファイルを実行。公開版に同梱しないモーション素材への依存を修正し、該当項目と変更箇所を再実行して確認。外部素材を読む検査は素材配置時だけ実行する形に分離。
- 初期設定9件、バックアップ復旧4件が成功。架空データを使った検査です。
- 実ブラウザーで、名前入力、会話の表示、履歴表示、再読み込み後の保持、代替画像の読込を確認。表示確認用の定型返信であり、実AI接続の新規導入試験ではありません。
- 公開対象に対する秘密情報スキャン。検出された4か所は既知のテスト用ダミー文字列であることを確認し、該当行だけを明示的に除外して再確認。
- 個人用環境の実際の設定値との一致を検査し、一致なし。秘密値自体は記録・公開していません。
- キャラクター・アイコンは独自の代替画像、壁紙は公開対象の4枚に限定。原画・モデル・音源を含めません。

## 今回の対象外

新しいクラウドDBの作成から全機能を使うまでの実環境通し確認、各OS・各スマートフォンでの再検証、全DBの復元、一般公開サービス向けの負荷・侵入試験は未実施です。ブラウザーを起動する自動E2E一式とDBテスト一式も、今回のソース公開では実行していません。

通常Webビルドには大きいJavaScriptファイルへの警告が残ります。ビルド失敗ではありませんが、初回読込の改善余地があります。

## 公開版を更新するとき

独自の修正後は `pnpm typecheck`、`pnpm build`、変更範囲のテストを実行します。公開前に `git add` したうえで `pnpm check:public` と秘密情報スキャナー（例：Gitleaks）を実行してください。

`check:public` は除外対象のファイルと、同梱画像の承認済みハッシュを確認します。素材を各自で入れ替えても、そのままGitへ上げないようにする補助です。新しい自作画像を公開する場合は、権利・内容を確認して `.public-assets.json` を更新します。この検査だけで秘密や権利の問題を完全検出するものではありません。
