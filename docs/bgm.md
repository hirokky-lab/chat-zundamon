# BGM

ヘッダーの♪で曲の選択・再生・停止を操作します。声との音量バランスは詳細設定にあります。停止したBGMをメニュー操作だけで再開しません。発話中は音量を下げ、音声入力・通話中は停止します。

音源は同梱していません。各配布元の利用条件を確認し、本人用の設置先へ配置してください。

| 曲 | 作者・配布元 | 配置先 |
| --- | --- | --- |
| 昼下がり気分 | [KK](https://dova-s.jp/bgm/detail/4695) | `data/bgm/hiru.mp3` |
| かえるのピアノ | [こおろぎ](https://dova-s.jp/bgm/detail/568) | `data/bgm/kaeru.mp3` |
| 自宅にて | [KK](https://dova-s.jp/bgm/detail/4041) | `data/bgm/jitaku.mp3` |

本人認証後の `/api/bgm/:track` で取得する構成です。表示確認モードでは音源を再生できません。未配置・取得失敗はプレーヤーに表示します。
