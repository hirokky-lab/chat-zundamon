# モーション見本帳

メニュー → モーション見本帳。ローカルLive2Dのずんだもんモデルが有効なときに表示する。

- 公式モデル同梱の動き23件、表情19件、ポーズ13件を実際のCubismレンダラーで表示。
- 動きを押すと一回再生。同じ動きを再度押すと先頭から再生。SDKの終了通知に合わせて停止表示へ戻る。
- 再生／停止、繰り返し、全指定のリセット。表情・ポーズは独立指定で組み合わせ可能。「指定なし」で元のモーションを確認。
- 会話の自動揺れを上乗せしない。現在の選択は会話へ自動採用せず、ページを閉じると破棄。
- PCは左にモデル・右に選択肢。スマホは上にモデル、下の一覧をスクロール。戻る／Escapeでメニューへ。
- 読み込み失敗時は静止画と再読み込み。端末の動きを減らす設定と既存の描画能力判定を維持。

## 実装

`AvatarStage` と署名ハッシュ検証を行う既存ローダーを共有。見本帳と通常トークは同じハッシュ検証済み `motion-gallery.json` を共有する。通常トークで自動再生する動きは、下記の採用済み12種類に限定する。
`prepare-zundamon.mjs` は既存の公式アーカイブのSHA-256検証後、`prepare-motion-gallery.mjs` でJSONをひとつにまとめ、一覧・ハッシュを `motion-gallery-catalog.ts` へ生成する。元JSONのURLを実行時に辿らない。

`motion-gallery-player.ts` がSDKのモーション管理を使用。SDKが要求するeffect ID配列を初期化する。表情は公式JSONのAdd/Multiply/Overwriteを反映し、腕のポーズの絵は中間値でフェードさせない。各フレームでモデルの既定値から評価し、前の表情やポーズを持ち越さない。

通常トークのレンダラーはメニュー表示中に解放済み。見本帳を閉じるとそのレンダラーも破棄し、既存のSDK共有状態の直列化を維持。

## 通常会話への採用（2026-09-12）

| 場面 | 使用する動き |
| --- | --- |
| 怒る | 怒る |
| 笑う・喜ぶ | 笑う3／顔：笑う（交互） |
| 否定 | 首を振る2 |
| 返答・音声の準備中、考える | 考える3 |
| 怖がる | 震える |
| はずかしい・照れる | 手を振る／顔：照れる（交互） |
| 挨拶 | 手を振る3 |
| 同意 | うなずく |
| 悲しむ | 顔：悲しむ |
| 驚く | 顔：驚く |

- 選択は `conversation-motion.ts` に集約。現段階ではAIの感情タグではなく、返答の冒頭の言い回しによる控えめな判定。説明文に含まれる「怒る」「怖い」だけでは反応させない。判定に当たらない返答は通常の待機動作になる。
- 1つの返答グループに1回。セリフ分割で同じ動きを繰り返さず、保存済みの履歴を開いても再生しない。考え中もループさせない。
- 発話中は音声の口パクを優先。腕の絵の切替は半透明にせず、動きが終わったら通常動作へ戻す。ギャラリーの自由な試し再生はそのまま。
- `node scripts/live2d/verify-conversation-motions.mjs` はローカルの実SDKで採用モーションを描画し、`output/conversation-motion-verification/` に確認用フレームを保存する。実音声は使用しない。
